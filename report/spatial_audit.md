# 空间问答歧义审计（2026-09-23）

空间题只给物体类别名，例如“人位于车的左边还是右边？”。当图片里有多个人或多辆车时，
同一句问题可能同时有“左边”和“右边”两个正确解释。训练模型去猜一个未指定的实例，
会把标注随机性误当成视觉能力。本审计逐条读取原始 VOC XML 中的物体中心坐标，
枚举提问涉及的两类物体的所有配对；如果左右答案同时出现，标记为歧义。

| 空间样本状态 | 总数 | test 中数量 |
| --- | ---: | ---: |
| 所有配对方向一致，可保留 | 1,333 | 76 |
| 同一句题可同时回答左和右，剔除 | 661 | 33 |
| 无有效方向或标签不一致，剔除 | 6 | 0 |
| 合计 | 2,000 | 109 |

去歧义后仍保留原始 `splits.json` 的 image_id 分组和所有 8,000 条非空间题；
清理版共 9,333 条，train/val/test 为 8,383/461/489，空间题 1,333 条。
原始 10k 数据未覆盖。供本地门禁使用的 1k 子集在五类任务中各取 200 条。
详细逐条审计与清理脚本见 `report/spatial_audit.json`、`scripts/audit_spatial.py`。

用已修复批量解码的旧 Baseline 权重在原始 test 做回溯比较：

| 子集 | 旧 Baseline 原图 | 同题错图 | 无图问题频率基线 |
| --- | ---: | ---: | ---: |
| 方向明确的 76 题 | 36/76 = 47.4% | 40/76 = 52.6% | 29/76 = 38.2% |
| 歧义的 33 题 | 21/33 = 63.6% | 20/33 = 60.6% | 16/33 = 48.5% |

原图在明确空间题上还未超过错图，不能仅凭 47.4% 的正确率声称学会了左右关系。
歧义题的“正确率”依赖生成脚本选择了哪一对实例，本身不适合作为能力指标。
清理数据消除了这类标签歧义，但不能保证模型一定利用视觉；必须重训并在同一批明确题上
继续做原图、错图和无图三方对照。该对照只有一组错图映射和一次训练，适合筛查问题，
不作为稳定效果的统计证明。
