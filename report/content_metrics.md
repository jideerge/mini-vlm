# 内容评分 v1

适用范围：本项目 VOC 中文模板问答。实现位于 `evaluation/metrics.py`。
这是保守的规则解析器，不是通用中文语义评审器；标准答案优先取 JSONL 的 `meta`。

| 任务 | 内容正确的定义 |
| --- | --- |
| counting | 数量一致；支持阿拉伯数字、零到九、两、十到九十九；重复相同数量可接受。若显式提到类别，必须与所问类别一致。 |
| existence | 明确的有/无或是/否与标签一致；同时肯定和否定则无法解析。若显式提到类别，必须与问题一致。 |
| spatial | 左右一致；完整关系必须按问题的主体、参照物顺序表达。倒置关系、同时出现左右或不确定表达均不猜测。 |
| attribute | 主要物体类别一致；多个不同类别无法确定主要物体，归为无法解析。 |
| listing | VOC 类别集合完全相等；忽略顺序和重复，同时提供逐样本 precision/recall/F1 的宏平均。 |

## 指标口径

- `correct`：内容正确数 / 全部样本数。无法解析不会从分母中排除。
- `parsed`：能够明确抽取答案的比例，必须与正确率一起看。
- `status_counts`：`correct`（明确正确）、`wrong`（明确错误）、`unparsed`（无法解析）的数量。
- `correct_nonexact`：内容正确但旧整句匹配不通过，占全部样本的比例；不一定都是重复，也可能是简短表达或同义数字。
- `reference_prefix_extra`：输出以完整参考答案开头，但后面还有内容。它可能继续说错，不能独立当作正确。
- `repetition_detected`：检测到重复的标点分隔片段，或完整参考答案重复出现。仅是重复迹象，不覆盖所有重复形式。
- 列举任务的宏平均指标中，无法解析样本按零分计算。

旧整句 exact / prefix 指标保留。新增指标不能直接与旧版多数类整句基线比较。
规则不支持的同义表达、未知类别、含糊或矛盾答案会被归为无法解析；
因此这不是无偏的真实语义准确率。应抽查逐条结果，避免把解析覆盖不足误认为模型看错。

## 结果可复核性

`scripts/evaluate.py` 保存原图和错图的全部逐条结果，包括样本 id、meta、生成文本、
抽取值、标准值、状态和续写标记。后续改进评分规则可以直接重新评分这些文本，
不必为评分变化重新运行模型。

## 验证

测试覆盖等价数值、错误数量、矛盾/否定、不确定表达、问答对象错位、
左右主体颠倒、集合顺序与重复、额外类别、部分集合 F1、单字重复和数值标点边界。
同时保留视觉错位回归测试。

```powershell
& ..\venv\Scripts\python.exe -B -m unittest discover -s tests -p 'test_*.py' -v
```
